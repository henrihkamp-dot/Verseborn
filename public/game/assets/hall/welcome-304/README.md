# Ember Hall guest sprites

Generated with built-in image_gen, using the existing Hall Mira and Kael action sprites as rendering guides and each guest atlas as identity reference. Six 100px cells per guest, three columns by two rows. Main-cast art is always loaded from the actual Hall assets. Revus rig uses one side-view drawing, animated by runtime joints; the atlas is not played as a walk cycle.

Guests: Revus Veln, Nyx, Rava, Jory. Prompt intent: compact three-head-tall overworld proportions, warm low-resolution shaded clusters, matching Hall detail density; retain identity, costume and accessories, transparent background.
