# Flameguard comic inserts

Built-in image_gen illustrations with the canonical character sheets as identity references. Rendering/framing follows Verseborn comics: black ink panel edges, cream gutters, expressive colored manga and selective chibi reactions. Nine optimized illustrated inserts; the four existing Sparky/Revus cutaways use the same frame system.

Canon anchors:
- How Seerin Got Her Groove Back, PDF page 3 (printed page 2): relic-of-shame poster, 40% more cape, huge shoulder pads and difficulty looking left. The earlier heroic arena draft was rejected; final seerin-tornado.webp depicts the costume gag.
- The Little Engineer Makes Her Case, PDF pages 4 and 6: rank/usefulness versus belonging, professional-name gag, panic becoming machinery. The new welcome is an adaptation after the separate Stonewake visit, not a replacement for the bar opening or a claim that the special's later tests already happened.
- Original Issue 3, PDF page 11: Glinda/professional names, the locking hinge and Torren's collapse, deadpan team banter.

Final prompts and original generated paths are recorded in tools/comic-306-generation.json; tools/comic-306-revisions.json takes precedence for Seerin's costume and Glimmer's return. Final files in this directory are used by welcome-comic-panels.js only. No new illustrations are inserted into Tinus, Sleeping Dragon, or the opening construction scene.
