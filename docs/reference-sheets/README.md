## Important continuity notes

- **Kael is clean-shaven and bald.**
- **Seerin is a tiefling paladin**, with auburn/red hair, horns, white-and-red Flameguard plate, sword and shield.
- **Mira is a half-elf rogue/ranger** in black, wearing her top hat and using twin lilac/voidthorn daggers.
- **Torren is a broad, heavily armored dwarf earth guardian**, with long red-brown hair and beard and a stone shield.
- **Glimmer is a tiny pink-haired gnome engineer** with goggles, white coat, tools and gadgets.
- **Sparky is the tiny purple-black dragonling**, not a humanoid dragon.
- **Verseborn is human**, black-haired, hooded, lute-bearing, and visually distinct from the Flameguard inquisitor look.
- **Marla** is the practical human tavernkeeper/caretaker associated with the Drunk Lantern in the Ash Quarter.
- **King Maeric Cindralis** is the weary human king of Cindervale in the supplied royal reference sheet.
- **Ember Hall** is the Flameguard home/reference state shown in its dedicated location sheet. For Issue 3 specifically, use the script's ruined/pre-restoration state instead of the restored-home sheet.
- **Guildspire** and **The Drunk Lantern** use their dedicated location sheets for architecture, interiors, signage, scale and atmosphere.

## Use by Work / Codex

When generating or editing assets for the new run:

1. use the new-run script/roadmap for plot, dialogue, page structure and issue-specific state;
2. use these reference sheets for visual identity;
3. use issue-specific script instructions when they intentionally differ from a general location/reference sheet;
4. never allow pre-revamp material to silently override new-run canon.
