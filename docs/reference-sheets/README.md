## Important continuity notes

- **Kael is clean-shaven and bald.**
- **Seerin is a tiefling paladin**, with auburn/red hair, horns, white-and-red Flameguard plate, sword and shield.
- **Mira is a half-elf rogue/ranger** in black, wearing her top hat and using twin lilac/voidthorn daggers.
- **Torren is a broad, heavily armored dwarf earth guardian**, with long red-brown hair and beard and a stone shield.
- **Glimmer is a tiny pink-haired gnome engineer** with goggles, white coat, tools and gadgets.
- **Sparky is the tiny purple-black dragonling**, not a humanoid dragon.
- **Verseborn is human**, black-haired, hooded, lute-bearing, and visually distinct from the Flameguard inquisitor look.

## Use by Work / Codex

When generating or editing assets for the new run, use this folder as the visual reference index and prefer these sheets over older artwork or pre-revamp depictions.

### Binary source note

The PNGs were supplied as ChatGPT conversation attachments. This GitHub integration can commit text and Git objects but does not expose a direct local-file upload parameter for these binary attachments in this workflow. The filenames above therefore identify the authoritative source sheets; the binary images should be placed under `docs/reference-sheets/images/` when binary upload is available.
