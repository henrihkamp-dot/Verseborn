# High-end Personal Artifact tier and immediate equipment inspection

The sets now target the strongest normal Ember Stage 50–60 Artifact drops. Native Artifact budget is 78; Stage 60 applies 1.45, for about 113 base points. Each personal piece has 125 total base points (about 10% higher), distributed by role and slot; all five-piece sets share 625 total points before tempering. Every item has five curated affixes at the Stage-60 upper roll, respecting existing combat caps. Support and controller duration bonuses use whole actions. The weapon, necklace and first ring retain their personal skill/gameplay effects in addition to those five affixes.

Existing copies migrate once to the five-affix tier. Subsequent player affix rerolls are preserved; canonical base stats continue to respect the earned temper rank. New drops are stamped with the current balance version. Destiny Ring II is excluded. The user's latest release export (6) is updated in the existing output file, without changing progression or its Destiny rings.

Clicking an occupied equipment slot now selects that exact equipped reference and opens Item details immediately. It closes the Auto Equip panel so the item can be read. Item details include an inline copy of the five affix descriptions, retaining the separate native modifier controls and the inventory browser. Empty slots still open the inventory browser.

Validated: all forty 125-point budgets, exactly five upper-roll affixes each, personal effects on weapon/necklace/first ring, role/ownership restrictions, actual drop pools, Stage-60 set grant, release export loading, Team Gear Test, unchanged Destiny rings/progression, and slot-click inspection of the correct equipped item with all five affixes visible.
