## Canon handling

- The main-series revamp PDFs are treated as the current main-series sources.
- Two uploaded candidates exist for **The Ballad That Lied**. Neither is marked canonical here until the preferred version is explicitly chosen.
- Two uploaded candidates exist for **The Multi-Angle Mixer / Guild Mixer**. Neither is marked canonical here until the preferred version is explicitly chosen.
- Metadata files should record only what is supported by the source comic or an explicit canon decision.

## PDF storage

Preferred future paths:

- `docs/comics/main-series/pdfs/`
- `docs/comics/specials/pdfs/`
- unresolved duplicate candidates: `docs/comics/review/`

The attached PDFs are image-heavy documents. The GitHub connector available in this chat can create and edit text files, but it cannot transfer local binary PDF attachments directly into the repository. The index and canon structure are therefore committed here first; PDFs can be added to the paths above when binary upload is available.
